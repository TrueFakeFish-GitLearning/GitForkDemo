# Contributing

Thank you for contributing to this repository.

## Workflow

1. Create or choose an issue.
2. Create a branch from `main`.
3. Make and commit your changes.
4. Push the branch to your fork.
5. Open a pull request to the upstream `main` branch.
6. Wait for required checks and review.
7. Merge the pull request after all requirements are satisfied.

## Branch naming

Use short and descriptive branch names, for example:

- `feature/add-example`
- `fix/readme-typo`
- `docs/update-guide`
- `ci/update-workflow`

## Pull requests

Keep pull requests focused and concise.
